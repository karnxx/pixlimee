Pixel editor.
It is a simple editor with color picking, exporting, changing dimensions, transparency. it is for small pixel editing and uses a simple grid based art system. 
It uses Python, namely the pygame and tkinter library.
Its my first time doing this, so i learnt how to make actual python programs and especially programs focused on creating art.
i had many issues, i didnt know where to begin. so i started by making a pygame window. then i added like a random color pixel system( my pixels are 20x20px). then i made all the pixels into one color and represented them using coordinates corresponding to a color in a dictionary. then i made it so that when the plr lmbs, it takes the coordinate of the mouse on the screen, divs x and y by 20 (pixl size), and then corresponds tht to the pixel dict and changes the value. and then after that i worked on the color picking system, where i learnt hsv and rgb. i added a transparency modifier too.
lmb to draw, rmb to erase, esc to exit.
